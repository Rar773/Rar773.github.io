ClipFarm Uploader - Privacy Policy

ClipFarm Uploader is a private tool used only by its owner (Marian Marton) to upload short videos to his own YouTube channels.

Data accessed: the tool uses the YouTube Data API only to upload videos, read basic channel information and video statistics of the owner's own channels.

Storage: access tokens are stored only on the owner's personal computer. No data is shared with, sold to, or transferred to any third party.

Revoking access: access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
